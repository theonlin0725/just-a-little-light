# 就差一点光 · V2 光学试玩

这是可直接导入微信开发者工具的**小游戏**试玩包，不需要安装依赖、不需要联网。

## 导入

1. 打开微信开发者工具 → **导入项目** → 选择本目录 `wechat-v2-demo/`。
2. 项目类型选 **小游戏**。
3. AppID：
   - 直接选「测试号 / 游客模式」即可本地试玩；
   - 如果提示 AppID 无权限或测试号不可用，把 `project.config.json` 里的 `"appid": "touristappid"` 改成你自己的小游戏 AppID（仓库正式包用的是 `wxa2d0086126adf6fb`）。
4. 点击编译。

## 进入光学试玩

- 进入游戏后，点首页的 **「V2 光学试玩 · 5 个新机制」**。
- 想跳过首页直接进第 1 关：在开发者工具的「编译模式 / 启动参数」里填：

```text
beam=0
```

`beam=0..5` 对应 6 个演示关：

| 参数 | 关卡 | 机制 |
| --- | --- | --- |
| `beam=0` | 初折 | 45° 棱镜偏折 |
| `beam=1` | 初染 | 蓝滤镜染色 |
| `beam=2` | 叩门 | 分光 + 锁存机关开门 |
| `beam=3` | 寻向 | 摇杆调发射角 |
| `beam=4` | 虹现 | 色散三色 |
| `beam=5` | 限时 · 初折 | 15 秒倒计时 + 全亮冻结 |

## 玩法

- 拖动发光的灯座、棱镜、滤镜；摇杆关按住灯座下方的手柄拨动。
- 目标全亮后会冻结倒计时，连续保持 **3 秒**通关；松手不会中断保持。
- 引导关有幽灵手、虚线框和分步提示；前 5 关不限时，第 6 关限时 15 秒。

## 说明

- 这是 Gate 1 的纵向切片，**不是正式 21–60 关**；经典 60 关仍保留在首页「开始 / 选关」里。
- 广告位未配置，试玩不依赖广告。
- 正式包目录是 `../wechat/`；这个 `wechat-v2-demo/` 只是方便试玩的副本。
