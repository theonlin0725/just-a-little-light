## 0. 一页结论

### 0.1 诊断：用户不是玩腻了，是没被接住

40–60 秒的停留，通常不是「关卡太长/太短」，而是五个流失点叠加：

| # | 流失点 | 用户心里的原话 | 现在的设计 |
| --- | --- | --- | --- |
| 1 | 不知道怎么玩 | 「我要把这个球拖去哪？」 | 第一关只有一行字，没有手把手 |
| 2 | 没有下一步 | 「过了一关，然后呢？」 | 只有「下一关」，没有星级/货币/章节 |
| 3 | 3 秒是空白 | 「找到了，然后等 3 秒」 | 3 秒是进度条，不是玩法 |
| 4 | 关卡同质 | 「怎么又是拖到下面某个位置」 | 60 关共用一条难度轴 |
| 5 | 没有回来的理由 | 「明天再玩也行」 | 没有每日、收藏、社交、故事 |

### 0.2 三个抓手

1. **接住**：前 3 分钟用「做」来教，不用文字教；第一次通关在 30 秒内发生。
2. **留住**：给一个 3–5 分钟的 session 剧本——教学 → 首胜 → 首星 → 章节宝箱 → 第一套皮肤。
3. **玩深**：把「找位置」升级成「找路径 + 找时机」；让 3 秒从等待变成维持。

### 0.3 核心改动

```
第一幕·影之篇（点光源投影）           第二幕·光之篇（定向光束与光学元件解谜）
1–10 初见·拖光避影 → 11–20 流影·动态与双灯 → 21–28 折光·移动棱镜 → 29–36 染光·移动滤镜 → 37–44 启封·光学机关 → 45–52 寻向·摇杆控光 → 53–60 光谱·分光与合成
```

## 1. 诊断：40–60 秒到底丢在哪

### 1.1 现在的循环

```
打开 → 首页 → 第 1 关 → 拖光 → 3 秒 → 通关 → 下一关 → …
```

这个循环里，**玩家每 30 秒才获得一次反馈**（通关），而且反馈只有「下一关」。对短视频/小游戏用户来说，30 秒没有新信息，就会退出。

> **用户原话（节选）**
>
> - 「前期关卡缺乏引导关：用户进去之后其实不知道该怎么样移动光源，以及要达成什么样的目标才能通关。」
> - 「目前已有的玩法主要是移动光源、移动双光源、躲避障碍物，以及延时 3 秒通关……后面 30 关到 60 关需要重新设计。」
> - 「现在这 60 关从用户体验上来讲，其实都更方便通关，因为手指只需要在屏幕下方移动。」

这三句话分别对应：**不会玩、太单一、太舒服**。V2 的三个抓手就是对着这三件事去的。

### 1.2 五个流失点的设计对策

| 流失点 | 不是…… | 而是…… | 对策 |
| --- | --- | --- | --- |
| 不会玩 | 玩家笨 | 第一关没有「必须做对」的引导 | 三步交互教学，第一步就必须拖动 |
| 没目标 | 玩家没耐心 | 通关后没有可见的下一目标 | 星级、光尘、章节宝箱、皮肤进度 |
| 3 秒空白 | 玩家嫌慢 | 找到答案后没有新决策 | 让障碍/镜子在保持期间继续动 |
| 关卡同质 | 玩家喜新厌旧 | 60 关只有一条「找位置」轴 | 位置 → 路径 → 时机/颜色 |
| 不回来 | 玩家不忠诚 | 没有每日理由和收藏 | 每日星图、星座、皮肤、回声 |

### 1.3 一次 3–5 分钟的 session 剧本

这是 V2 最重要的设计物：**第一会话的逐分钟脚本**。

| 时间 | 发生什么 | 玩家获得 |
| --- | --- | --- |
| 0–10s | 首页只有一个「开始」；点开后直接进入第 1 关，幽灵手指拖动光球 | 「原来是这样拖」 |
| 10–30s | 第一颗水晶亮起，3 秒环出现，通关；光尘 +10，星级 +1 | 第一次「我做到了」 |
| 30–60s | 第 2 关教影子；第 3 关教双目标；每关 20–30 秒 | 连续三次小胜利 |
| 60–90s | 第 4 关移动障碍；首次三星；光尘约 90；商城图标出现红点 | 「我可以买点什么」 |
| 90–150s | 第 5–6 关；失败一次，1 秒内重试；第一次想「再来一次」 | 紧张感 + 掌控感 |
| 150–210s | 第 7–8 关；用 120 光尘买下「微光」拖尾并装备 | 第一次收藏/个性化 |
| 210–270s | 第 9–10 关；第 1 章宝箱 +100；星座第一段连线 | 第一次「章节完成」 |
| 270–300s | 回主页看星座图；「明日星图」预告；第一套皮肤还差一点光尘 | 「明天再来」 |

> 这张表是目标节奏，不是硬性脚本。关键是：**3 分钟内至少有 1 次三星、1 次购买、1 次章节反馈**；否则用户没有理由留下。

**关键**：不是把每关做长，而是把「下一个反馈」的间隔压到 20–30 秒，并在 3 分钟内给一次「大反馈」（宝箱/皮肤）。

### 1.4 目标用户与场景

| 用户 | 场景 | 他们想要 | V2 对应 |
| --- | --- | --- | --- |
| 碎片玩家 | 地铁/电梯/排队，1–3 分钟 | 点开就会、每关短、随时能停 | 三步教学、20–30 秒关、自动下一关、断点续玩 |
| 解谜爱好者 | 晚上 10–20 分钟 | 新机制、难度、可钻研 | 镜子/棱镜、三星、挑战模式、回声 |
| 收藏/分享型 | 微信聊天/朋友圈 | 好看、有战绩、能晒 | 光尘商城、皮肤、星座、分享卡 |

> 先服务「碎片玩家」把留存跑通，再服务「解谜爱好者」做深度；不要一开始就为硬核玩家把关卡做难。

## 2. 核心设计：单指三阶演进，四条解谜深度轴

### 2.1 单指直觉操控的三阶渐进演化

为了同时承载「棱镜折反、滤镜变色、机关解锁、光源调向、色散合成」五大光学玩法，同时坚守微信小游戏**竖屏单手可玩、零技能按钮、不双指同搓**的底线，操作方式随章节分三阶自然解锁：

| 阶段 | 关卡范围 | 光源形态 | 玩家单指操控对象 | 核心体验 |
| --- | --- | --- | --- | --- |
| **第一阶：拖光寻影** | 第 1–20 关 | 全向散射点光源 | 拖动**光球位置** | 在阴影夹缝与移动障碍间寻找稳定站位 |
| **第二阶：移件筑路** | 第 21–44 关 | **初始发射角固定、底座可平移**的聚光灯座 | 拖动**灯座位置** + 拖动场上的**棱镜、滤镜**（棱镜朝向固定不手动旋转） | 移动光源与元件，用 1–3 次折反、染色与两步开机关搭建光路 |
| **第三阶：移位 + 摇杆调角 + 移件协同** | 第 45–60 关 | **可平移且带外圈弧形自锁摇杆**的聚光灯座 | 按住灯芯**拖动灯座位置** + 拨动外延摇杆柄**调发射角（松手自锁）** + 拖动**棱镜/滤镜/合光晶格** | 光源位置、初始发射角与光学元件三维联动，涌现一关多解与光谱合成 |

所有新机制都必须满足四条手感铁律：

- **任何时刻只需一根手指**：摇杆采用「拨动自锁（Drag-and-Lock）」，调好发射角松手即固定，再去拖棱镜或滤镜，绝不要求双手同时按住；
- **光学微吸附拒绝像素级瞄准**：拖动元件或拨动摇杆使光束末端靠近水晶/机关中心 `±3°`（或平移 `±8px`）时触发轻阻尼磁吸，消除三跳折射的手抖挫败；
- **防挡手交互布局**：延续上下竖屏布局；光源摇杆采用灯座下侧弧形拨槽，手指始终在光路下方滑动，不遮挡上方光束与水晶；
- **每次失败都能一眼看懂原因**：光被挡停在障碍表面、颜色不对在水晶外圈弹开排斥波纹、异色滤镜吸收冒出微光斑。

### 2.2 四条深度轴

| 深度轴 | 玩家在思考的问题 | 对应章节与机制 |
| --- | --- | --- |
| **空间站位** | 光站在哪，影子才不挡住水晶？ | 1–20 关：散射投影、多目标、移动挡板、双灯分工 |
| **几何路径** | 光要经过哪几块棱镜、折几次才能绕进死角？ | 21–28 关起：45° 偏折棱镜、90° 全反棱镜、半透分光棱镜（1→2→3 次折反） |
| **状态与时序** | 该染什么色？先照亮哪个机关开门，再怎么改光路点亮水晶？ | 29–44 关起：红/黄/蓝滤镜、锁存机关（两阶段重构光路）、保活机关（双路并供） |
| **发射角与光谱合成** | 初始角度往哪偏更省元件？白光拆成红黄蓝后怎么交汇合成紫/橙/绿？ | 45–60 关：自锁方向摇杆、色散三棱镜、合光晶格、多解路线涌现 |

### 2.3 把 3 秒从「干等」变成「确认与守光」

- **静态/纯逻辑光学关**：全亮瞬间冻结关卡倒计时，光束加粗发光、和弦逐层叠满，玩家可以松手欣赏自己搭好的 3 次折反/彩虹合流光路稳定充能 3 秒（松手不中断保持，避免手指遮挡画面与疲劳）。
- **动态窗口/摇杆追光关**（第 2 章部分关及第 6–7 章高阶关）：全亮后倒计时同样冻结，但场上的移动挡板或慢速滑行水晶仍在运动，玩家需在最后 3 秒内顺势微调光球或轻拨摇杆守住光束。

> 设计口诀：**「搭通光路是破题，守满三秒是落定。」**

### 2.4 六条设计原则

1. **单指分步闭环，摇杆松手自锁，绝不做双指搓招。**
2. **难度来自光路规划、先后时序与色彩推理，不来自 0.5° 像素微操。**
3. **新机制必有 1–2 关「白送」渐进引导，教会为止、绝不在教学关判超时失败。**
4. **难度曲线呈「锯齿波浪上升」，拒绝连续平铺同质关，章中必设喘息爽关。**
5. **广告不挡路，货币不卖通关。**
6. **渲染与判定严格同源**：画出来的折射角、颜色与混色结果，100% 就是通关判定的几何依据。

### 2.5 有趣的本质：每 10–15 秒一次「假设 → 摆件/调角 → 光路即时响应」

| 阶段 | 玩家做什么 | 游戏即时给什么 |
| --- | --- | --- |
| 假设 | 观察水晶颜色、封闭石门与棱镜切面 | 水晶颜色符号、机关到石门的虚线能量连线 |
| 试探 | 拖动棱镜/滤镜或拨动光源摇杆 | 实时重算 1–3 跳虚线预览光路，靠近目标轻吸附变实 |
| 阶段反馈 | 滤镜染色 / 机关「咔哒」开门 / 两光合成新色 | 玻璃音阶上行（Do-Mi-Sol）、石门缩回震动、合光漩涡 |
| 终局落定 | 全水晶被正确色光点亮并保持 3 秒 | 倒计时青色冻结、全屏光谱共鸣、结算星级与光尘 |

## 3. 全流程渐进式引导体系：每个新玩法 1–2 关「白送」上手

### 3.1 现状痛点：只有第 1 关远远不够

v0.5 全程 60 关仅在 `src/tutorial.js` 里写了 7 句静态文字，没有任何手势示范、落点框选与分步响应。一旦引入棱镜、滤镜、机关、摇杆、色散混色五大新玩法，如果只靠顶部一行字说明，休闲玩家会在新章节首关立刻懵住流失。

**核心策略：把引导从「开局前 3 分钟」扩展为「贯穿全 7 章的机制入口白送体系」。** 每解锁一个新玩法，先给 **1–2 关「白送级」渐进引导关**——不考脑筋急转弯、不设倒计时失败、直接用视觉交互把动作喂到嘴边，让玩家在 15–25 秒内亲手触发一次「哦！原来它是这么用的！」的正反馈，第 3 关再撤掉拐杖独立解题。

### 3.2 渐进引导「视觉三件套」（Tutorial Triad）

所有引导关统一由数据驱动的轻量组件渲染，零大图素材、纯 Canvas 绘制：

1. **动态幽灵手势（Ghost Hand）**
   - 半透明暖白发光手指图标，按住待操作对象（光球 / 棱镜 / 滤镜 / 摇杆手柄），沿示范轨迹匀速滑向目标虚线框，停顿 0.4s 后淡出循环。
   - **让位与唤醒**：玩家手指一触屏立即 0.15s 淡出，绝不挡视线；若玩家连续 **8 秒**未产生有效推进，幽灵手势轻柔重播。
2. **呼吸虚线方框 / 目标刻度槽（Dashed Target Zone）**
   - 在白送关中，用圆角**呼吸虚线方框**标出棱镜/滤镜的建议落点（摇杆引导关则在弧形导轨上标出高亮目标刻度槽）。
   - **宽容吸附确认**：元件拖入虚线框中心 `±18px` 自动柔顺吸附居中，虚线框转为青绿实线轻闪一下并消隐，给予明确的「放对了」确认感。
3. **分步门控轻提示 Toast（Step-Gated Toast）**
   - 画面上方悬浮圆角半透明胶囊 Toast，单条严格控制在 **14 字以内**，**做完上一步才弹出下一步**，绝不一开局堆砌长句。
   - 示例（第 37 关·机关首关两步引导）：
     - Step 1：虚线框 A 闪烁 + 手势把棱镜拖向 A → Toast：`「拖棱镜进框，先照亮机关开门」`
     - Step 2（机关充能满、石门缩回瞬间触发）：框 A 消失、框 B 亮起 + 手势从 A 移向 B → Toast：`「门开了！再把棱镜移去照亮水晶」`
     - Step 3（水晶点亮瞬间）：Toast：`「稳住 3 秒即可通关」`

### 3.4 引导关防打扰与兜底原则

- **老玩家丝滑越过**：白送关本身只需 10–15 秒即可完成，不设强制锁屏动画；只要玩家自己直接把元件拖到位，剩余引导步骤自动静默完成并直接过关。
- **独立关智能轻扶（Nudge）**：非引导关默认不显示虚线框；若玩家在同一关连续超时/重开 3 次，免费弹出气泡提示「试试先把光折向左上方的机关」或高亮第一个关键棱镜的大致区域，不弹强制广告。

### 3.5 引导验收指标

- 第 1–3 关基础引导完成率 ≥ 88%，首次通关中位用时 < 25 秒；
- 第 21、29、37、45、53 五大新机制首关首次通过率 ≥ 90%，平均耗时 < 30 秒；
- 新机制第 2 关到第 3 关（撤除虚线框首战）的留存折损 < 8%。

## 5. 玩法模块详解：五大光学新机制

### 5.0 光学底座切换与手机端微吸附规则

为什么第 21 关起从「全向散射点光源」切换为「定向聚光束（Beam）」？

- 全向点光源向 360° 散开，穿过多个棱镜、滤镜与色散合光时，手机小屏上光影重叠几乎不可读，且不存在「初始发射角度」的概念；
- 切换为**锐利清晰的定向光束**后，1 次、2 次、3 次折反轨迹、滤镜变色点、机关触发线与三原色交汇点在竖屏上一目了然。

**手机触屏手感护城河（防微操挫败）**：

- **可移动元件底圈**：凡是玩家可拖动的棱镜、滤镜、合光晶格，底部均绘制柔和呼吸圆托盘；固定焊死的镜面或电网滤镜则画铆钉石座，一眼区分可动与不可动。
- **触摸抬高偏移（Touch Offset）**：延续 v0.5 上下布局传统，按住棱镜/滤镜拖动时，元件判定中心相对指腹略微上移 `24px`，手指不遮挡晶体内折射光斑。
- **软磁吸（Optical Soft Snap）**：当玩家拖动棱镜或拨动光源摇杆，使最末跳出射光扫过水晶/机关中心 `±3°`（或元件距理想光路交点 `±8px`）时，提供轻微磁吸阻尼与触觉轻点，松手稳稳锁定，绝不出现「松手瞬间歪 1 像素射偏」的挫败。

### 5.1 模块一：棱镜玩法（折射与全反射，1→2→3 次折反接力）

玩家通过拖动场上**不同光学特性的棱镜**摆入光路，改变光束方向以绕过掩体、照亮水晶或开启机关：

| 棱镜类型 | 视觉特征（零贴图 Canvas 绘制） | 光学行为 | 核心解谜定位 |
| --- | --- | --- | --- |
| **45° 偏折棱镜（左偏/右偏）** | 青白半透明斜切三棱柱，内部带折射导光纹 | 光束穿过晶体发生**折射偏转 `±45°`** | 斜穿窄缝、微调绕障、Z 字折线 |
| **90° 全反直角棱镜** | 等腰直角三棱镜，长斜面镀银白高光膜（暗背吸光） | 光束从直角面射入发生**`90°` 全内反射**（从背面射入则被暗背阻挡） | L 型大拐弯、U 型 **3 次折反** 绕后探入封闭石室 |
| **半透分光棱镜** | 对称菱形晶块，中轴一道半透银线 | 一束光拆成 **`50% 直穿 + 50% 侧向 90° 反射`** 两束同色光 | 同时服务两颗水晶、一路守保活机关 + 一路穿门、复制稀缺原色 |

**多次折反的可读性与反馈设计**：

- **跳数梯度**：关卡主线重点设计 **1 次 → 2 次 → 3 次折反**（引擎上限支持 4 跳，超出后光束渐隐消散防死循环）；玩家不仅要找摆放坐标，还要判断**哪块棱镜放第一跳、哪块放第二/第三跳**。
- **晶体内部光路**：光束并非碰到棱镜中心突兀折弯，而是清晰画出「入射点 → 晶体内高亮折射段 → 出射点亮斑」。
- **音阶递进**：光束每多命中一颗棱镜，触发依次升高的清脆玻璃泛音（第 1 跳 `Do`、第 2 跳 `Mi`、第 3 跳 `Sol`），连成三折时自带听觉爽感。

### 5.2 模块二：透镜 / 滤镜玩法（移动改色、同色开启、异色截断）

玩家单指拖动场上的圆框**彩色滤镜（红 / 黄 / 蓝）**切入光路，改变光束颜色以匹配特定颜色的水晶与机关：

- **三条自洽色彩物理规则**：
  1. **白光染色**：纯白光穿过红/黄/蓝任一滤镜，出射光变为对应纯色光；
  2. **同色畅通**：红光穿过红滤镜（或复合紫光穿过红滤镜提取红光）可正常透射；
  3. **异色吸收截断**：已被染成纯红的光束若再撞上蓝滤镜或黄滤镜，光会被滤镜**吸收截断**（滤镜表面浮现柔和吸收光晕，光不再往前走）。这条规则衍生出极佳的解谜空间——例如「必须先用白光分光，再在各支路分别染色」（第 32 关），以及固定异色滤镜充当「选色门禁」（第 33、35 关）。
- **水晶与机关的颜色判定**：
  - **白色水晶/机关**：接受任意颜色光（白光或任意彩光均可激活）；
  - **彩色水晶/机关**：仅接受**颜色完全匹配**的光束；若被白光或错色光射中，目标外圈荡开一圈排斥虚线波纹、核心不亮，明确告知玩家「位置对了，但颜色不对」。
- **色盲无障碍双编码**：不单靠颜色区分，每色绑定专属几何内核徽记——红 `△`、黄 `✦`、蓝 `◇`、紫 `✡`（双三角叠合）、橙 `☀`、绿 `❖`、白 `○`，滤镜外框与水晶/机关中心同步绘制对应徽记。

---

### 5.3 模块三：光学机关玩法（两阶段先后破锁 vs 双路持续供能）

光不仅直接点亮水晶，更是解开场地封锁的**钥匙**。机关与其受控物（升降石门、水晶护罩、导轨滑台）之间始终用带流向粒子的细能量虚线相连，因果关系零黑盒：

| 机关子类型 | 图标标识 | 触发与维持规则 | 催生的核心解题思路 |
| --- | --- | --- | --- |
| **锁存型机关（Latch）** | 圆形底座 + **锁扣开锁符** | 对应色光连续照射 **0.8 秒**，外环充能满「咔哒」**永久锁定开启**；此后光束移开石门也不会关上 | **两阶段空间重构**：玩家用仅有的 1–2 颗棱镜/滤镜先搭出「开锁光路」打开水晶前的石门或推出远端滑台，随后**拆掉原光路重新挪动元件**搭出「点晶光路」通关！还可设计「开 A 门会同时落副闸封死 B 路」的先后顺序谜题（第 40 关） |
| **保活型机关（Hold）** | 圆形底座 + **呼吸常亮环** | 光束**照射期间**门保持敞开；一旦断光，0.3 秒缓冲后石门重新合拢 | **双路并发供能**：单束光挪走门就关，逼迫玩家动用半透分光棱镜、色散三路光或穿透式站位，实现「一路死死喂住机关，另一路穿门点亮水晶并共同维持 3 秒」（第 41、44 关） |

### 5.4 模块四：光源位置移动 + 发射方向操控（内芯移位 / 外柄自锁调角 + 多解涌现）

前五章（21–44 关）灯座可拖动位置，但**初始发射角度固定**，让玩家先吃透棱镜与滤镜摆放；从第六章（第 45 关）起，灯座外围解锁**「下置弧形自锁追光摇杆」（Arc Aim Joystick）**，实现**既能移灯座位置、又能改初始发射角**：

```
             ╲    ↑    ╱        ← 允许旋转的扇区边界（限位铆钉提示 ±θ）
              ╲   │   ╱
               ( 灯芯 )          ← 内圈热区（r ≤ 28px）：按住拖动 = 平移整座光源位置
                  │
            ╭─────●─────╮       ← 外圈下置拨槽 + 摇杆圆柄（距灯芯 56px）：
                                   按住滑动 = 改变初始发射角，松手即自锁固定！
```

- **为什么用「内芯移位 + 下置外柄自锁」双层热区设计**：
  1. **热区物理隔离零误触**：内芯（平移灯座）与外延圆柄（旋转角度）中心间距 `≥ 56px`，视觉造型一内一外截然不同，手机单指点按互不串扰；
  2. **松手自锁，单指分步**：拨好角度抬手即锁死不回弹，同一根大拇指接着去移灯座、移棱镜、移滤镜，无需双指同按；
  3. **零手指遮挡**：摇杆拨槽位于灯座背光下侧安全带，滑动调角时上方整片光学场地一览无余；
  4. **范围双可控**：每关可独立配置灯座可移动区域/导轨 `bounds` 与摇杆扇区限位 `angleRange`（如 `±25°` 窄扇、`±75°` 广角或 `360°` 灯塔）。
- **与棱镜、滤镜、机关叠加出的三大新玩法**：
  1. **开放多解（殊途同归）**：同一关既可以「拨向左路配红滤镜开机关直穿」，也可以「拨向右路用双棱镜折两次绕柱直击」（第 47、52 关），给不同思维习惯的玩家自由度，并用三星时间/巧解徽章奖励更优路线；
  2. **灯塔扫射连开多锁**：左右拨动摇杆配合不同滤镜依次点亮多座锁存机关，层层剥开中央水晶大门（第 48、50 关）；
  3. **3 秒保持期动态追光**：水晶缓慢横移时，元件搭好折射桥后，玩家只需在最后 3 秒轻推摇杆微调入射角，隔着棱镜远程操控末端光束稳稳跟住水晶（第 51 关）。

### 5.5 模块五：光的分解与合成（白→红黄蓝，交汇合成紫/橙/绿）

第七章（第 53 关起）将几何路径与色彩代数推向高潮，采用玩家直觉零门槛的**美术三原色（RYB）分解与合成体系**：

1. **白光色散（分解）**：
   - 元件：**色散三棱镜（Dispersion Prism）**——体积略大、内部绘有微光彩虹光谱纹的等边三棱镜（玩家可拖动）。
   - 行为：一束纯白光射入后，在出射面扇形分解为 **红光（左偏 `-25°`）、黄光（中轴 `0°`）、蓝光（右偏 `+25°`）** 三束独立原色光！每束原色光都可继续被后续的偏折/全反/分光棱镜独立引导。
2. **色光合并（合成）**：
   - **混色全表**：
     - **红 + 蓝 = 紫光（Purple）**
     - **红 + 黄 = 橙光（Orange）**
     - **黄 + 蓝 = 绿光（Green）**
     - **红 + 黄 + 蓝 三束齐聚 = 纯白圣光（Pure White）**
   - **两种清晰的合光载体（彻底解决手机端两线交叉看不清去向的问题）**：
     - **载体 A：合光晶格（Combiner Node，主推）**：半透明六边形晶格（部分关固定、部分关可拖动）。当两束不同原色光从任意入射面射入同一颗合光晶格时，晶格中心亮起混色漩涡，并沿晶格箭头出射口**合并射出一束全新的合成色光**（如紫光），可继续折射去开紫色机关或点亮远处紫水晶！
     - **载体 B：水晶多光直照合色**：若一束红光与一束蓝光直接同时命中同一颗紫水晶，水晶内部自动融合两色光并点亮。
   - **防忘配方贴心设计**：凡涉及混色的关卡，右上角常驻极简半透明「三原色交叠微图例」；玩家轻点场上的紫/橙/绿水晶或机关时，目标旁也会浮现 1.5 秒气泡（如 `红 △ + 蓝 ◇ = 紫`），绝不考死记硬背。

### 5.6 设计底线与不做清单

- **不做双指同时操作**：绝不出现「左手按住不自锁的摇杆、右手同时拖棱镜」的反人类手机操作。
- **不做无吸附的 0.5° 像素级刁难**：所有 2–3 次折反与摇杆角度均配微吸附与 `≥ ±2.5°` 容错窗口。
- **白送引导关绝不加硬计时**：全部 15 个机制教学关零超时失败，学会再考。
- **不做随机光学与黑盒机关**：机关连线全部可视化，所有 60 关必须 100% 通过光学求解器验证。
- **不做「必须看广告才给够棱镜/滤镜」的付费卡点**：每关自带元件必可满星通关。

## 6. 时间系统：20 秒怎么加才不劝退

### 6.1 采纳你的规则，但分阶段

你的建议：

> 设置 20 秒的关卡时限，必须在 20 秒内通关。当连接上并触发 3 秒倒计时时，这 20 秒倒计时冻结。

这条规则很好，原因是：

- 它把「找解」变成有时间压力的决策；
- 冻结让玩家在最后 3 秒不用怕超时，3 秒是奖励，不是惩罚；
- 它制造了「最后一秒找到」的高光时刻。

但**不建议所有关都硬性 20 秒**，尤其是 30–60 的镜子/棱镜关：

- 第一次见到新机制，玩家需要观察；20 秒会逼他乱拖；
- 复杂关的解法需要 2–3 步，20 秒不够；
- 失败太频繁会让人退出，而不是「再来一次」。

**V2 的做法：分阶段，不是取消硬计时。**

| 阶段 | 计时 | 作用 |
| --- | --- | --- |
| **学习期（1–20 关）** | 软计时（par）：超时不失败，只影响星级 | 先让新用户学会，不被时间吓走 |
| **主线（21–60 关）** | 硬计时：按复杂度给 20–45 秒，超时失败 | 兑现「有时间压力」的核心体验 |
| **挑战模式（通关后）** | 更紧的 20 秒 / par；双倍光尘 + 排行 | 给老玩家重玩理由，不影响首次通关 |

**21 关起，计时是真的会失败的。** 但失败成本要低：

- 失败后 1 秒内可「重试」，不用回选关；
- 连续失败 3 次，免费给一次方向提示；
- 失败不扣光尘、不扣体力、不弹广告；
- 每关的时间预算按「最短解 + 3 秒保持 + 观察余量」配置，不是拍脑袋 20 秒。

这样既保留了你想要的 20 秒紧张感，又不把第一次见机制的新用户挡在门外。

### 6.2 冻结规则

```
关卡开始 → 计时待机（不扣时）
第一次拖动 → 计时开始
全亮 → 计时冻结 + 3 秒保持开始
保持中断 → 计时恢复（0.5 秒宽限）
保持完成 → 通关，计时停止
面板/广告/后台 → 计时暂停
```

细节：

- **第一次拖动才计时**，不是加载就计时；否则玩家看画面也在扣时间。
- **全亮瞬间冻结**：计时器变蓝、音效「咔」、3 秒环变亮；玩家明确知道「我抢到了」。
- **中断恢复**：给 0.5 秒宽限，避免「刚断就 0.0 秒」的挫败；宽限每关一次。
- **超时失败**：不黑屏；画面定格，显示「差 0.8 秒」，一键重试；不自动弹广告。
- **时间奖励**：剩余时间 × 系数 → 光尘/星级；让「快」有意义，但不用「快」惩罚。

### 6.3 时间预算表

| 关卡类型 | 对应关卡 | 主线硬计时 | 三星 par | 说明 |
| --- | --- | ---: | ---: | --- |
| **全部渐进引导关（白送/半白送）** | **1–3, 11, 13, 15, 16, 21–22, 29–30, 37–38, 45–46, 53–54** | **无（免失败）** | — | 零压力学会新机制，15–25s 必拿首胜 |
| 第一幕学习期（影之篇非引导关） | 4–10, 12, 14, 17–20 | 无硬败（软计时） | 18–28s | 超时不判负，只影响星级 |
| 第三章 棱镜折反（1–3 跳） | 23–28 | 25–35s | 16–24s | 含喘息关 25s、三折与试炼 35s |
| 第四章 滤镜变色 | 31–36 | 25–35s | 18–25s | 先分后染与三路配镜留足观察余量 |
| 第五章 光学机关（两步锁存/保活） | 39–44 | 30–45s | 22–32s | 两阶段挪动元件重构光路需更宽预算 |
| 第六章 摇杆控向与多解 | 47–52 | 30–45s | 20–32s | 鼓励探索巧解，动态守光关留足容错 |
| 第七章 分光与混色终章 | 55–59 / **60** | 35–50s / **60s** | 25–36s / **42s** | 多元件色彩合成与终章四步交响 |

> 20 秒是「短关」的标准，不是所有关的教条。用户提出 20 秒的意图是「增加紧张感」，不是「让所有关都变成速通」。

### 6.4 UI 与反馈

- 计时器放在屏幕上方，跟关卡号同一行；不要挡住光路。
- 正常：暖白；最后 5 秒：琥珀；冻结：青色 + 「时间冻结」小字。
- 最后 5 秒：每秒一声轻滴，不刺耳；不要红色闪烁。
- 冻结瞬间：3 秒环从光源外圈亮起，音乐加一层。
- 超时：画面轻暗，显示「差 0.8 秒 / 再试一次」；不要「失败」两个大字。

### 6.5 防挫败

- 连续失败 3 次：免费给一次方向提示（不自动播广告）。
- 失败后 1 秒内可点「重试」，不用回选关。
- 挑战模式失败不扣光尘、不扣体力。
- 不做「看广告复活/加时」——那会把失败变成付费点。

### 7.3 星级

- 1 星：通关。
- 2 星：在 par 时间内通关。
- 3 星：par 时间 + 不用提示 + 不重开。

### 7.4 经济平衡

- 日均产出：约 100–150 光尘（含每日、首通、广告 3 次）。
- 第一套皮肤 300：2–3 次 session。
- 第二套 600：约 1 周。
- 不做通胀：新皮肤价格按「日均产出 × 5–7 天」定。
- 广告产出不超过日均 50%；光尘类广告每日 3 次硬上限，全部激励视频每日最多 5 次。
- 防作弊：本地存档；排行榜/云端前不做可交易资产。

### 7.5 为什么这样设计

用户说「每关给用户的正向反馈还不太够」。光尘不是目的，**它是把「通关」变成「到手」的可见反馈**：

- 通关 → 光尘数字跳动 → 商城红点 → 下一个目标；
- 三星 → 额外光尘 → 重玩有意义；
- 章节宝箱 → 大反馈 → 3 分钟节点。

### 8.1 广告位（只做激励视频）

| 位置 | 触发 | 奖励 | 频控 |
| --- | --- | --- | --- |
| 通关结算 | 点「光尘 ×2」 | 本关光尘 ×2 | 每日 3 次 |
| 提示面板 | 点「看广告解锁定位」 | 定位提示 | 每日 3 次 |

**全局上限**：每日最多 5 次激励视频；任意两次之间至少间隔 60 秒。

**不做**：插屏、banner、开局广告、失败复活广告、强制广告。

### 8.2 体验规则

- 第一次广告出现在**第 3 关通关后**，不要在 onboarding 里弹。
- 广告按钮必须写清「看广告，光尘 ×2」，不能伪装成普通按钮。
- 广告播放期间：关卡冻结、计时冻结、音乐压低；回来后不发奖两次。
- 无填充/加载失败：按钮变灰，显示「广告暂不可用」，不诱导重试。
- 广告完成才发奖；取消/未看完不发；用令牌防重复。
- 广告不遮挡 3 秒保持；不在保持阶段弹任何东西。

### 8.3 技术流程

```
关卡开始 → 预加载广告
玩家点「×2」→ 生成 reward token → show()
  ├─ onClose(isEnded=true) → 校验 token → 发奖 → 标记已领
  ├─ onClose(false) → 不发奖
  ├─ onError → 显示不可用 → 允许重试一次
  └─ 超时 → 关闭 loading → 不发奖
```

- `adUnitId` 放在 `config/wechat.config.json`；空值时不创建广告实例。
- 每个广告位独立 ID；方便看填充率/eCPM。
- 广告回调绑定「关卡 + 局次」令牌；切关/重开后旧回调作废。
- 广告期间 `game.pause()`；恢复后不补算时间。
- 真机验证：iOS/Android 各一台；无填充、取消、后台切换。

### 8.4 商业化节奏

## 9. 沉浸感：让光像一个生命

> 沉浸不是「画面更炫」，而是三件事同时成立：**我能看懂**（能力感）、**我知道下一步**（目标感）、**世界有回应**（惊喜）。V2 的沉浸设计都围绕这三件事。

### 9.1 星座地图：给「下一关」一个意义

- 60 关不是 60 个冰冷的格子，而是 **7 座主题星座**，对应两幕七章。
- 每通关一关，点亮一颗星；每章完成，星座连线浮现，播放 3 秒无字声光动画并开启章节宝箱。
- 终章第 60 关通关后：七座星图汇聚点亮整片天幕，出现「你点亮了这片天空」。
- 章节地图是主页的第二屏，不是弹窗；玩家随时能看到「这章还差几颗星」。
- 七座星图名：**初见、流影、折光、染光、启封、寻向、光谱**。每章一句短诗，不强制阅读。

### 9.2 无字叙事

- 开场：一片黑，一颗散射微光；没有长文，只有一个「开始」。
- 第 20 → 21 关转场：散射光球凝缩为一束锐利白光，象征从「寻影」步入「驭光」。
- 每章完成：星座亮起，浮现本章光学图腾（影 / 潮 / 棱 / 镜 / 钥 / 盘 / 虹）。
- 终章：红黄蓝三原色重聚为纯白圣光升入天幕。叙事是通关奖励，绝不打断操作。

### 9.3 声音：折射音阶与混色和弦

- **棱镜折反音阶**：光束连续穿过第 1、2、3 颗棱镜时，依次响起 `Do - Mi - Sol` 上行玻璃泛音，听觉直接反馈跳数。
- **滤镜与合光音色**：穿过滤镜染色时叠入温暖木管泛音；两束光在合光晶格合成紫/橙/绿光瞬间，奏响双音程和谐共鸣。
- **机关解锁反馈**：锁存机关 0.8s 蓄满时发出清脆石锁「咔哒」与低频门启声。
- **保持 3 秒与通关**：每颗水晶亮起叠一层音高，全亮冻结时和弦完整，通关收束为清越钟琴。全部 WebAudio / 微信音频程序化合成，零音频包体积。

### 9.4 触觉

- 水晶首次亮起：短振动。
- 全亮冻结：两下轻振。
- 保持每秒：极轻脉冲（可关）。
- 通关：一次长振。
- 设置里可关触觉；iOS/Android 差异做降级。

### 9.5 皮肤人格

- 皮肤不只是颜色：拖尾形状、音色、命中粒子的性格。
- 青焰：冷、轻、拖尾长；赤潮：暖、重、光柱粗；星砂：碎光、钟琴音。
- 皮肤描述用一句话人格，不用数值。
- 皮肤试用 24 小时（广告），让玩家先感受再买。

### 9.6 分享、回声、好友

- **分享卡**：星座、关卡、用时、星级、皮肤；「我在 12.4 秒点亮了猎户座」。
- **回声**：记录自己最好一次的轨迹，下次以半透明「影子光」重放；和自己比赛。
- **好友排行**：微信开放数据域，先做好友榜，不做全服榜；只比已通关关卡。
- **异步接力**：好友的「影子光」帮你照亮一个目标（后期实验，不做 MVP）。

### 9.7 每日星图

- 每天 3 个短关（15–25 秒），同一套种子，所有人一样。
- 奖励 60 光尘 + 1 次宝箱；连续 7 天给皮肤碎片/拖尾。
- 分享「今日星图」成绩；不强制。
- 这是最低成本的日活钩子。

### 10.2 几何光学求交与 3-bit RYB 色彩引擎（`optics.js`）

- **色彩位掩码代数（3-bit RYB Bitmask）**：用 3 位整数统一表达原色、滤镜吸收与色光合成，零分支歧义且前后端求解器 100% 同构：
  - 原色定义：`RED = 0b001 (1)`，`YELLOW = 0b010 (2)`，`BLUE = 0b100 (4)`，`WHITE = 0b111 (7)`；
  - 合成色：`ORANGE = RED | YELLOW (0b011 = 3)`，`PURPLE = RED | BLUE (0b101 = 5)`，`GREEN = YELLOW | BLUE (0b110 = 6)`；
  - **色散三棱镜**：输入 `WHITE (0b111)` 时拆出 `-25°(RED)`、`0°(YELLOW)`、`+25°(BLUE)` 三条子射线；若输入单色/双色掩码 `M`，仅在对应位非零的折射角输出原色子射线；
  - **彩色滤镜（减色透射）**：掩码为 `F` 的滤镜作用于光束 `C`，输出 `out = C & F`——白光 `0b111 & RED = RED`（染色）；红光撞蓝滤镜 `0b001 & 0b100 = 0`（吸收截断）；紫光过红滤镜 `0b101 & 0b001 = RED`（提纯！）；
  - **合光晶格 / 水晶多光汇聚（加色合成）**：同一目标或合光晶格收到多束光 `C_1, C_2...` 时，合成色 `mixed = C_1 | C_2 | ...`；彩色水晶/机关要求 `mixed === requiredMask`（白色通用水晶要求 `mixed > 0`，纯白圣晶要求 `mixed === 0b111`）。
- **射线追踪与微吸附**：
  - 每条光束最多追踪 `maxBounces = 4` 跳（关卡主解设计在 1–3 跳）；
  - 渲染层与通关/机关状态机读取同一份 `traceBeams()` 输出，杜绝「画亮了但没判定上」。

### 10.3 计时器与机关状态机

```
计时器：idle → running → frozen（全水晶颜色匹配点亮）→ won
                     ↘ expired（引导关不进入此分支）
锁存机关：locked → charging (0..0.8s) → unlocked（本局永久保持，除非点重来）
保活机关：closed ↔ open（受光即开，断光 0.3s 缓冲后合拢）
```

## 13. 风险与对策

| 风险 | 概率 | 影响 | 对策 |
| --- | --- | --- | --- |
