> 2026-10-26。基于第二轮版本增量修改；游戏名、AppID、存档键 `projection.save.v3`、60 关难度与"同时点亮保持 3 秒"规则均未改变。

## 一、布局基础：三层分离 + 全屏背景

| 层 | 做法 | 代码 |
|---|---|---|
| 背景层 | 按 **cover** 缩放到整个 canvas（含信箱区），渐变/浮尘/噪点铺到屏幕边缘 | `render.js` `drawFullBleed()` |
| 玩法层 | 世界整体旋转 90°，等比铺进一条 720×448 的"玩法带" | `src/layout.js` + `render.js` |
| 界面层 | 仍用 contain 坐标，标题/说明/按钮/弹窗不旋转；刘海与胶囊由 `viewport.js` 的安全区约束 | `viewport.js`、`render.js` |

- 相机像素尺寸、窗口、DPR、触摸换算仍是 `viewport.js` 一份真值；旋转只是叠加在它之上的一层变换。
- 背景不再出现"整块画面缩在中间 + 上下黑条"：信箱区被背景覆盖，实测 390×844 与 720×1280 两种比例都没有纯黑边。

## 二、全关卡旋转（左/右 → 上/下）

**没有改关卡数据**：世界仍是 720×1280 逻辑坐标，墙是竖的、光从左右照。旋转只发生在呈现层：

```
sceneToScreen: 屏幕 = band + R(θ)·(scene)
screenToScene: 输入按同一变换的逆变换回到逻辑坐标
```

- `src/layout.js`：`computeSceneLayout / sceneToScreen / screenToScene / sceneMatrix / screenDirToScene`。
- 单侧关自动选择旋转方向，让**目标墙落在玩法带上沿**：墙在世界左侧（1–24 镜像后）顺时针；墙在世界右侧（25–36）逆时针。
- 双侧关（37–60）旋转后天然是**上、下两面墙**，光源在中间。
- 触摸：`pointerDown/Move` 先判断是否落在玩法带内，再逆变换到逻辑坐标；底部按钮仍用屏幕坐标。
- 方向键微调：`nudge(dx,dy)` 先把屏幕方向转成逻辑方向。
- 方向提示：把光源与解算点都投到屏幕，再算八方向，所以"往上挪"就是屏幕上往上。
- 教学文案：`左右两侧` → `上下两侧`；第 39 关的关卡名"左右"在展示层改为"上下"（数据未动）。

**等价性证据**：`tests/playthrough60.test.mjs` 60/60 关用真实触摸事件（经旋转逆变换）通关；`tests/layout.test.mjs` 覆盖坐标往返、带内命中、方向映射、60 关渲染冒烟。

## 三、双光源机制（27–30）

- 灯旁边画 **1 / 2 身份圆牌**（选中时高亮），与画面位置绑定，不旋转。
- 需要两盏灯的晶体旁画两个小牌（1、2），已满足的点亮，并显示 `1/2` 进度；全满足时变青色。
- 单灯晶体不挂标记，避免 60 关满屏噪音；归属由光束本身表达。
- 第 27 关文案仍为"带两个点的水晶，要两盏灯同时照到"。
- 29/30 关两盏灯分别负责不同晶体，因此不会出现"双灯同照"的标记（只有 `lights.length >= 2` 的晶体才有）。

## 四、提示阈值 4

- `HELP_NUDGE.failedAttempts` 默认 **4**（可配置），0.3 秒防抖、单次亮灭只计一次、暂停/后台/广告/重开/通关都不计。
- 文案改为「差一点就成功了，点灯泡看看提示吧。」（无广告位时用"免费提示"）。
- 频控与冷却保持：每局 1 次、同关会话 2 次、重开 60 秒冷却。
- 回归：`tests/nudge.test.mjs` 17 项按新阈值动态断言。

## 五、BGM：从低频嗡鸣改为稀疏旋律

- 去掉原来的三音低频 pad（110/165/220Hz 长音），改成**五声音阶琶音**：0.62 秒一音、每 4 音略延长、每 8 音留空拍，音区 C4–E5。
- 音色：三角波 + 轻微失谐泛音（钟琴感），短衰减包络；一条 0.27 秒反馈延时做空间感。
- 低八度只在乐句起点轻轻托底（音量 0.022），不再是持续低音。
- 启停淡入淡出、`clearInterval` 清理调度器；切关/后台/关音乐都不会叠加多份。
- **无法验证**：我听不到真机输出，也无法在此环境导出试听文件（没有离线渲染管线）。需要你实机听感确认。
