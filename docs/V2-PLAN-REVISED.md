## 1. 核心决策对齐（结合 2026-11-19 最新玩法方向）

| 模块 | 最新定案设计 | 工程与体验护栏 |
| --- | --- | --- |
| **光学底座切换** | **1–20 关（第一幕·影之篇）**保留全向点光源投影；**21–60 关（第二幕·光之篇）**切换为**定向聚光束** | 定向光束让 1–3 次折射、滤镜变色、机关触发与三原色合光在手机竖屏上一眼可读，并为后期解锁「改变初始发射角」奠定几何前提。 |
| **1. 棱镜玩法（21–28 关起）** | 玩家单指拖动 **45° 偏折棱镜、90° 全反直角棱镜、半透分光棱镜**，完成 **1 次 → 2 次 → 3 次折反** | 拖动时实时绘制虚线预览光路，末端靠近水晶/机关 `±3° / ±8px` 触发软磁吸，消除三跳手抖挫败；折反命中触发 `Do-Mi-Sol` 上行玻璃音。 |
| **2. 透镜/滤镜玩法（29–36 关起）** | 玩家拖动 **红/黄/蓝滤镜** 改变光色，匹配特定颜色水晶与机关；异色滤镜吸收截断纯色光 | 采用 `3-bit RYB` 位运算（染色 `&`），衍生「先分光后染色」与「异色门禁」谜题；全色系配几何符号双编码（色盲友好）。 |
| **3. 机关玩法（37–44 关起）** | 先照亮机关解锁石门/护罩/滑台，再照亮水晶；含 **锁存型（0.8s 永久开门）** 与 **保活型（持续照射开门）** | 锁存型催生「同一批元件拆旧路搭新路」的两阶段时序解谜；保活型催生「分光一路守门、一路点晶」的空间并发解谜。机关与门之间全程绘制流向连线。 |
| **4. 光源移位 + 方向操控（45–52 关起）** | 灯座全程可拖动位置；第 45 关起解锁**下置外延弧形自锁摇杆**（按内芯移位置、拨外柄改发射角，松手自锁） | 内芯（`r ≤ 28px`）与外柄（间距 `56px`）热区隔离零误触；单手单指分步完成，结合棱镜/滤镜移动涌现**一关多解**与 **3 秒保持期微调追光**。 |
| **5. 光的分解与合成（53–60 关）** | **色散三棱镜**将白光分解为**红、黄、蓝**；经双光同照或**合光晶格**合成 **紫（红+蓝）、橙（红+黄）、绿（黄+蓝）、纯白（三色重聚）** | 合光晶格将两束入射原色汇流为一束新色光继续折射，解决手机端交叉光线去向不清的问题；右上角常驻三圆混色微图例防忘配方。 |
| **渐进式白送引导** | 全流程 8 大机制入口共设 **17 关「白送/半白送」引导关**（每新玩法 1–2 关） | 统一采用**幽灵手势 + 呼吸虚线方框（`±18px` 自动吸附）+ 分步门控轻 Toast（≤14字）**，且引导关一律 **无硬计时免失败**。 |
| **波浪上升难度梯度** | 每章 8 关采用「双白送 → 初试 → 顺序深化 → 跨章小高峰 → **喘息爽关** → 高阶变奏 → 章节试炼 Boss」 | 拒绝连续同质平铺关，章中固定安排视觉解压喘息关回血，章与章之间基准难度阶梯抬升。 |

## 3. 计时、保持、经济与广告执行口径

1. **倒计时冻结与 3 秒保持**：首次有效操作起算倒计时；全目标被正确色光点亮瞬间**冻结关卡倒计时**并启动连续 3 秒保持。静态逻辑关允许松手观赏充能；动态移动关需顺势微调守住光路。连续两次超时免费给气泡提示，四次超时提供免计时练习通关。
2. **光尘与商城**：首通 +10；第 5/10/20 关里程碑各 +50；章节宝箱 +100；新手 +60；三星 +15。按拖尾 120 / 皮肤 300 计算：第 5 关至少 160 光尘，可买拖尾；第 20 关至少 610 光尘，可买皮肤。广告只加倍首通基础奖励（+10，每日 2 次），不作用于里程碑/宝箱；分享不发货币。旧版已解锁皮肤在 v4 存档迁移中永久保留。
3. **激励视频广告**：首阶段仅在非引导关的首通结算卡开放自愿「看广告，光尘 ×2」（每日 2 次、全局 5 次；`src/ads.js` 已有单次请求令牌与并发/超时处理，但**每日上限是新增逻辑，不在现有 `ads.js` 内**），不在白送引导关、3 秒保持期或失败页弹任何广告。
4. **分批交付建议**：先跑通 `optics.js` + 引导三件套与 5 个新机制首关真机盲测（Gate 0）；建议按 **v2.0（1–28 关：影之篇 + 棱镜章）→ v2.1（29–44 关：滤镜 + 机关）→ v2.2（45–60 关：摇杆 + 光谱）** 三批推进。若坚持主方案的 v2.0 1–44 关，至少把 29–44 放在章节预览/灰度开关后，并保留退回 1–28 的能力。
