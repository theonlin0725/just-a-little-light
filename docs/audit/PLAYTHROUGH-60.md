## 交互层是怎么跑出来的

`tests/playthrough60.test.mjs`：每关新建 Game → 按真实顺序 `pointerDown → pointerMove（沿 BFS 绕障路径）→ pointerUp`，再以 1/60 步长推进直到通关。全程不修改 `lights.pos / phase / holdTime / unlocked / result`。

结果：**60/60**；不操作自动通关 **0/60**；23 关需要等待移动障碍的 3 秒窗口才通关（最长约 16 秒）。

本轮没有 Android / iPhone 设备，也没有真机调试通道。这一栏只能由设备实测填写，不能用开发者工具模拟器或微信 API 替身代替。
